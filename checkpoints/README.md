# Checkpoints

Pretrained checkpoints are intentionally kept separate from source code where convenient.

- `esc50/`: five student folds.
- `urbansound8k/`: reserved for UrbanSound8K checkpoints.
- `tau/`: reserved for TAU checkpoints.

The five ESC-50 binary checkpoint files were not present among the uploaded files used to generate this ZIP. Copy the actual `.pth` files into `checkpoints/esc50/` before evaluation.
